## 合规声明

本目录文档用于理解**自有** OpenCode 实例的流量结构、会话标识与上游校验行为，以及排查兼容性问题。
结论与探针脚本**不用于**伪造第三方客户端身份或绕过 free-tier / 配额 / 授权限制
（与 [`方案.md`](./方案.md) §9 一致）。
